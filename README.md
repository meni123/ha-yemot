Home Assistant Yemot Integration (ha-yemot)


אינטגרציה ל-Home Assistant המחברת בין מערכת הטלפוניה וה-IVR של ימות המשיח לבין הבית החכם.

📋 דרישות מוקדמות
לפני תחילת ההתקנה, ודא שיש ברשותך:

גישה חיצונית ל-Home Assistant: נדרשת כתובת חיצונית פעילה (כגון Nabu Casa, Cloudflare Tunnel וכדומה) כדי ששרתי ימות המשיח יוכלו לתקשר עם השרת שלך.

טוקן ניהול של ימות המשיח: ניתן להפיק את הטוקן בקלות מתוך לשונית אבטחה באתר הניהול של ימות המשיח.

🚀 מה התוסף עושה?
ניהול שלוחות טלפוניות: יצירה והגדרה אוטומטית של שלוחות IVR המקושרות ישירות לישויות ב-Home Assistant.

הקראת סטטוסים ושליטה בשיחה: מאזינים יכולים לשמוע בטלפון את מצב ההתקנים (כגון טמפרטורה, אחוזי סוללה, מצב דולק/כבוי) או לבצע פעולות (הדלקה/כיבוי) ישירות מתוך תפריט השיחה.

שירותי התראות ואוטומציות: שליחת הודעות קוליות (TTS) וצנתוקים ישירות מתוך אוטומציות וסקריפטים ב-Home Assistant (למשל לצורך התראות בית חכם).

📦 התקנה מהירה
העתק את תיקיית ha-yemot אל תוך תיקיית custom_components בשרת ה-Home Assistant שלך (/config/custom_components/ha-yemot/).

בצע אתחול (Restart) ל-Home Assistant.

היכנס להגדרות -> התקנים ושירותים (Devices & Services) -> הוסף שילוב, וחפש את Yemot API.

מלא בטופס את הכתובת החיצונית של ה-HA ואת טוקן הניהול של ימות המשיח.
