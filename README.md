# אינטגרציית ימות המשיח ל-Home Assistant
שם התוסף: `ha-yemot`

אינטגרציה ל-Home Assistant המחברת בין מערכת הטלפוניה וה-IVR של ימות המשיח לבין הבית החכם. 

**איך זה עובד?** 
התוסף מקים ממשק API מאובטח בתוך שרת ה-Home Assistant שלכם. שרתי ימות המשיח מתקשרים מול ה-API הזה בזמן אמת במהלך שיחת טלפון, מקבלים את הסטטוסים העדכניים של ההתקנים (חיישנים, מתגים וכו'), ומקריאים אותם למאזין או מבצעים פעולות על סמך הקשת מקשים.

---

## ⚠️ אזהרה חשובה: דריסת שלוחות!
שימוש בשירות "הגדרת שלוחה" (`create_extension`) דרך התוסף, מגדיר ומעצב מחדש את התיקייה במערכת ימות המשיח כתיקיית API. **פעולה זו דורסת לחלוטין כל הגדרה קיימת (קובץ `ext.ini`) באותה שלוחה!** 
יש לוודא שאתם משתמשים בשירות זה רק על שלוחות ריקות או שלוחות המיועדות ספציפית לבית החכם, כדי לא למחוק הגדרות שלוחות קיימות.

---

## דרישות מוקדמות
לפני תחילת ההתקנה, ודא שיש ברשותך:
* **גישה חיצונית לשרת HA:** נדרשת כתובת חיצונית פעילה (כגון Nabu Casa, Cloudflare Tunnel וכדומה) כדי ששרתי ימות המשיח יוכלו לפנות לשרת שלכם.
* **טוקן ניהול של ימות:** ניתן להפיק את הטוקן מתוך לשונית **אבטחה** באתר הניהול של ימות המשיח.

---

## התקנה והגדרה
1. העתיקו את תיקיית `ha-yemot` אל תיקיית התוספים המותאמים אישית בשרת שלכם:
   `/config/custom_components/ha-yemot/`
2. בצעו אתחול מחדש (Restart) ל-Home Assistant.
3. גשו אל **הגדרות** -> **התקנים ושירותים** -> **הוסף שילוב**, וחפשו את `Yemot API`.
4. מלאו בטופס את הכתובת החיצונית ואת הטוקנים הנדרשים. (ניתן להשאיר את שדה "כתובות IP מורשות" ריק בשלב הבדיקות, ולאחר מכן להזין את כתובות השרת של ימות לאבטחה מירבית).

---

## שירותים (Services) לאוטומציות

התוסף מנגיש 3 פונקציות מרכזיות לשימוש בתוך ה-Home Assistant:

### 1. ימות: הגדרת שלוחה (`ha-yemot.create_extension`)
הפונקציה מתחברת למערכת ימות המשיח, יוצרת שלוחה ומגדירה אותה אוטומטית לעבודה מול הישות המבוקשת ב-Home Assistant.
* **היררכיה בשלוחות:** ניתן לפתוח שלוחות פנימיות על ידי שימוש בלוכסן (`/`). לדוגמה: כדי ליצור את שלוחה 4 בתוך שלוחה 1, הזינו בשדה השלוחה `1/4`.
* **ישות (Entity):** הישות שאותה נרצה שהשלוחה תקריא (לדוגמה `sensor.temperature`).
* **פעולה (Action):** (אופציונלי) פקודה לביצוע כגון `turn_on` או `turn_off`.

### 2. ימות: שליחת צנתוק / התראה (`ha-yemot.send_tzintuk`)
שליחת צנתוק לרשימת מספרי טלפון להתרעה מיידית. תומך בהזנת מספר מציג (Caller ID) ייעודי.

### 3. ימות: הוצאת שיחה קולית (`ha-yemot.send_tts`)
ביצוע שיחה יוצאת למספרי טלפון והקראת טקסט חופשי (TTS - Text to Speech). מצוין להתראות קוליות מפורטות באוטומציות חירום או עדכוני מצב.
