# אינטגרציית ימות המשיח ל-Home Assistant

[![hacs][hacs-shield]][hacs-url]

חיבור מלא בין מערכת הטלפוניה וה-IVR של **ימות המשיח** לבין **Home Assistant**.

מאפשר לשמוע את מצב המכשירים בבית בשיחת טלפון רגילה, לשלוט בהם דרך הקשה בשלוחה, ולשלוח צנתוקים והודעות קוליות מתוך אוטומציות — בלי אינטרנט בטלפון ובלי אפליקציה.

## מה זה עושה

| שירות | קוד שירות | תיאור |
|---|---|---|
| הגדרת שלוחה | `ha_yemot.create_extension` | יוצר שלוחה בימות המקושרת לישות ב-HA — להקראת סטטוס ו/או ביצוע פעולה |
| שליחת צנתוק | `ha_yemot.send_tzintuk` | צנתוק למספר בודד, לרשימת מספרים או לרשימת תפוצה |
| הוצאת שיחה קולית | `ha_yemot.send_tts` | מחייג ומקריא טקסט, עם בחירת קול ומהירות דיבור |

> ⚠️ הדומיין הוא `ha_yemot` עם **קו תחתון**. שימוש במקף (`ha-yemot`) יחזיר שגיאת "שירות לא נמצא".

## התקנה

### דרך HACS (מומלץ)

1. **HACS** ← תפריט שלוש הנקודות ← **Custom repositories**
2. הדבק `https://github.com/meni123/ha-yemot`, קטגוריה **Integration**, לחץ **Add**
3. חפש **Yemot HaMashiach API** והתקן
4. **הפעל מחדש את Home Assistant** (restart מלא, לא "טעינה מחדש של YAML")

### התקנה ידנית

1. הורד את המאגר
2. העתק את **כל** תיקיית `custom_components/ha_yemot` אל `/config/custom_components/ha_yemot/`
3. הפעל מחדש את Home Assistant

> 💡 ודא שהעתקת גם את תיקיית `translations/`. בלעדיה הממשק יוצג באנגלית עם שמות שדות טכניים.

## ⚠️ שלב חובה: הגדרת proxy מהימן

**אל תדלג על השלב הזה.** בלעדיו הסינון לפי IP או ייכשל תמיד, או — גרוע יותר — ייתן לך תחושת ביטחון שגויה.

הוסף ל-`configuration.yaml`:

```yaml
http:
  use_x_forwarded_for: true
  trusted_proxies:
    - 127.0.0.1
    - ::1
    # אם ה-proxy רץ במכונה אחרת, הוסף את הכתובת שלו כאן
```

### למה זה קריטי

ההדר `X-Forwarded-For` הוא **טקסט חופשי שכל אחד יכול לשלוח**. אם התוסף היה קורא אותו ישירות, כל אדם באינטרנט היה יכול לכתוב בבקשה שלו "אני ימות המשיח" ולעקוף את כל הסינון בשורה אחת של `curl`.

ההגדרה הזו גורמת ל-Home Assistant לקרוא את ההדר **רק כאשר החיבור עצמו הגיע מ-proxy שסימנת כמהימן**. בקשה ישירה מהאינטרנט עם הדר מזויף — ההדר פשוט נזרק. התוסף קורא רק את התוצאה המאומתת.

## הגדרה ראשונית

**הגדרות** ← **התקנים ושירותים** ← **הוסף שילוב** ← חפש **Yemot HaMashiach API**.

| שדה | הסבר |
|---|---|
| **כתובת חיצונית** | הכתובת הציבורית של השרת. בדרך כלל תמולא אוטומטית מהגדרות הרשת של HA |
| **טוקן ניהול ימות** | נבדק מול שרתי ימות בזמן ההגדרה. שני הפורמטים נתמכים |
| **טווחי IP מורשים** | ברירת המחדל היא טווח שרתי ימות. השארה ריקה **מבטלת את הסינון** |
| **מספרי טלפון מורשים** | אופציונלי אך מומלץ מאוד. רק מספרים אלה יוכלו לשלוט בבית |

**טוקן האבטחה נוצר אוטומטית** כמחרוזת אקראית ארוכה ונשמר לצמיתות. הוא לא משתנה בהפעלה מחדש ולא בעדכוני גרסה. ניתן לצפות בו ולשנות אותו דרך כפתור **הגדרות** בכרטיס האינטגרציה.

## דוגמאות שימוש

**הקראת טמפרטורה בשלוחה 1/5**

```yaml
action: ha_yemot.create_extension
data:
  folder: "1/5"
  entity_id: sensor.living_room_temperature
```

**הדלקת אור בשלוחה 1/6**

```yaml
action: ha_yemot.create_extension
data:
  folder: "1/6"
  entity_id: light.salon
  action: turn_on
```

**התראה קולית כשדלת נפתחת**

```yaml
automation:
  - alias: התראה על פתיחת דלת
    triggers:
      - trigger: state
        entity_id: binary_sensor.front_door
        to: "on"
    actions:
      - action: ha_yemot.send_tts
        data:
          phones: "0501234567"
          message: "דלת הכניסה נפתחה"
          tts_voice: ymFemale
          tts_rate: -10
```

## 🔒 אבטחה — חובה לקרוא

התוסף פותח נקודת גישה אינטרנטית שמסוגלת **לשלוט פיזית בבית שלך** — כולל תריסים ומנעולים. הנקודה הזו חייבת להיות פתוחה לשרתי ימות, ולכן היא גלויה לאינטרנט. הקטע הזה מסביר מה נעשה כדי להגן עליה ומה נשאר באחריותך.

### שכבות ההגנה המובנות

**1. סינון IP עמיד בפני זיוף**
הבדיקה מתבססת על כתובת ה-TCP האמיתית (`request.remote`) ולא על הדרים שהשולח שולט בהם. ניסיונות זיוף דרך `X-Forwarded-For` או `X-Real-IP`, בכל מיקום בשרשרת, נחסמים.

**2. טוקן אקראי חזק**
נוצר ב-`secrets.token_urlsafe(24)` — כ-192 ביט של אקראיות. אין ברירת מחדל שניתן לנחש, ואין אפשרות "לשכוח לשנות את הסיסמה".

**3. השוואה בזמן קבוע**
`hmac.compare_digest` במקום `==`, כדי שלא ניתן יהיה לשחזר את הטוקן תו-אחר-תו לפי הבדלי זמני תגובה.

**4. רשימת היתר לפעולות**
רק דומיינים ופעולות בטוחים ניתנים להפעלה מרחוק. קריאה ל-`shell_command`, ל-`homeassistant.restart` או לכל שירות אחר שאינו ברשימה — **תיחסם גם אם הטוקן נכון**. זו השכבה שמגבילה את הנזק גם בתרחיש של דליפת טוקן.

**5. סינון לפי מספר מתקשר**
ימות שולחת את מספר המתקשר (`ApiPhone`). מספר שאינו ברשימה מקבל הודעה קולית שאין לו גישה. **זו שכבת ההגנה החזקה ביותר** — היא לא מסתמכת על סוד שעלול לדלוף.

**6. חיבור למנגנון חסימת ה-IP של HA**
טוקן שגוי מוחזר כ-401 ומדווח ל-`process_wrong_login`, כך שניסיונות ניחוש חוזרים מובילים לחסימה אוטומטית.

### 🔑 הטוקן הוא סיסמה לכל דבר

**התייחס אליו בדיוק כמו לסיסמת הכניסה ל-Home Assistant.**

הטוקן מוטמע בתוך כתובת ה-URL שהתוסף מייצר ושומר בשלוחה בימות, למשל:

```
https://ha.example.com/api/yemot/xK9mP2vR7nQ4wL8sT3jF6hB1/light.salon/turn_on
```

מכאן נובעות כמה מסקנות מעשיות:

- ❌ **אל תפרסם את הכתובת הזו בשום מקום** — לא בפורומים, לא בקבוצות תמיכה, לא בצילומי מסך ולא בדוחות תקלה. מי שרואה אותה רואה גם את הטוקן וגם את כתובת הבית שלך.
- ❌ **אל תשתף צילומי מסך של תוכן ה-`ext.ini`** בשלוחה — הקישור המלא נמצא שם.
- ⚠️ **הטוקן עשוי להופיע בלוגים** של ה-reverse proxy, של Cloudflare ושל HA. זה טבעו של טוקן שעובר ב-URL, וזו בדיוק הסיבה שרשימת ההיתר לפעולות קיימת.
- ✅ **אם אתה חושד שהטוקן דלף** — החלף אותו מיד דרך מסך ההגדרות, והרץ מחדש את `create_extension` עבור כל שלוחה קיימת.

### מה כדאי להיזהר ממנו

| סיכון | המלצה |
|---|---|
| **מנעולים חכמים** | אם המערכת שולטת במנעול, **מלא את שדה מספרי הטלפון המורשים**. אל תסתמך על הטוקן בלבד |
| **סינון IP מבוטל** | השארת השדה ריק פותחת את הנקודה לכל האינטרנט. עשה זאת רק לצורך אבחון ולזמן קצר |
| **HTTP במקום HTTPS** | הטוקן עובר בטקסט גלוי. אל תשתמש בתוסף בלי TLS |
| **`trusted_proxies` רחב מדי** | ערך כמו `0.0.0.0/0` מבטל את כל ההגנה. רשום שם רק את ה-proxy שלך |
| **חשיפת HA לאינטרנט** | התוסף מאבטח את נקודת הקצה שלו בלבד. אבטחת שאר השרת באחריותך |
| **`ip_ban_enabled`** | כבוי כברירת מחדל ב-HA. הפעל אותו כדי שהדיווח על ניסיונות כושלים ייכנס לתוקף |

### בדיקה עצמית

לאחר ההתקנה, ודא שההגנה פעילה:

```bash
# 1. גישה ללא הרשאה - אמור להחזיר 403
curl -s -o /dev/null -w "%{http_code}\n" \
  "https://YOUR-HA/api/yemot/WRONG-TOKEN/light.salon"

# 2. ניסיון זיוף IP - אמור להחזיר 403 (ולא 401)
curl -s -o /dev/null -w "%{http_code}\n" \
  -H "X-Forwarded-For: 2a13:8140:1::1" \
  "https://YOUR-HA/api/yemot/WRONG-TOKEN/light.salon"
```

**403** = נחסם על ה-IP ✅ &nbsp;|&nbsp; **401** = הזיוף עבר את שכבת ה-IP ❌ בדוק את `trusted_proxies`

> הרץ ממחשב או מטלפון חיצוני, **לא** מתוך תוסף Terminal של HA — משם הבקשה תגיע מ-`127.0.0.1` והתוצאה תהיה חסרת משמעות.

## פתרון תקלות

| תסמין | סיבה אפשרית |
|---|---|
| הממשק באנגלית עם שמות שדות טכניים | תיקיית `translations/` לא הועתקה, או נדרש restart מלא ו-`Ctrl+Shift+R` בדפדפן |
| `invalid_auth` בהגדרה | טוקן הניהול נדחה על ידי ימות. בדוק אותו באתר הניהול |
| השלוחה לא עונה / שקט | חפש בלוג `נחסמה בקשה`. אם מופיעה כתובת חדשה — זו הכתובת שממנה ימות פונים, הוסף אותה לרשימה |
| "נחסמה בקשה מכתובת פנימית" | חסרה הגדרת `trusted_proxies` — ראה [שלב חובה](#-שלב-חובה-הגדרת-proxy-מהימן) |
| "הפעולה המבוקשת אינה מורשית" | הפעולה או הדומיין אינם ברשימת ההיתר ב-`const.py` |
| השלוחה הפסיקה לעבוד פתאום | הטוקן הוחלף. הרץ מחדש את `create_extension` |

לאבחון מפורט, הוסף ל-`configuration.yaml`:

```yaml
logger:
  logs:
    custom_components.ha_yemot: debug
```

## ⚖️ הצהרת אחריות

> **התוסף מסופק כמות שהוא (AS IS), ללא כל אחריות מכל סוג שהוא.**
>
> השימוש בתוסף הוא **באחריותו הבלעדית של המשתמש**.
>
> המפתח אינו נושא באחריות כלשהי, ישירה או עקיפה, לכל נזק, אובדן, פריצה, גישה בלתי מורשית, תקלה, הפעלה שגויה של מכשירים, עלויות טלפוניה, או כל תוצאה אחרת הנובעת מהתקנת התוסף, מהשימוש בו או מאי-יכולת להשתמש בו.
>
> **בפרט, ומבלי לגרוע מן האמור:**
> - התוסף פותח נקודת גישה אינטרנטית לשליטה במכשירים פיזיים בבית. **הערכת הסיכון וההחלטה להתקין הן באחריות המשתמש בלבד.**
> - אמצעי האבטחה המתוארים במסמך זה נועדו להקטין סיכון, אך **אינם מבטיחים ואינם יכולים להבטיח** הגנה מוחלטת מפני גישה בלתי מורשית.
> - שילוב התוסף עם מנעולים, שערים, מערכות אזעקה או כל מכשיר שכשל בו עלול לגרום לנזק לרכוש או לגוף — נעשה **על אחריות המשתמש בלבד**.
> - המשתמש אחראי לאבטחת שרת ה-Home Assistant שלו, לשמירת סודיות הטוקן ולתצורת ה-reverse proxy שלו.
> - התוסף אינו מוצר רשמי של ימות המשיח ואינו נתמך, מאושר או מסופק על ידה. המפתח אינו קשור לחברה. שינויים ב-API של ימות עלולים לשבש את פעולת התוסף ללא הודעה מוקדמת.
> - המשתמש אחראי לעמידה בתנאי השימוש של ימות המשיח ולכל עלות הנובעת משימוש בשירותיה.

**התקנת התוסף ושימוש בו מהווים הסכמה מלאה לתנאים אלה.**
