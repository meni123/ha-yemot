# אינטגרציית ימות המשיח ל-Home Assistant
שם התוסף: `ha_yemot`

אינטגרציה ל-Home Assistant המחברת בין מערכת הטלפוניה וה-IVR של ימות המשיח לבין הבית החכם.

---

## דרישות מוקדמות
לפני תחילת ההתקנה, ודא שיש ברשותך:
* **גישה חיצונית לשרת:** כתובת חיצונית פעילה (כגון Nabu Casa, Cloudflare Tunnel וכדומה) כדי ששרתי ימות יוכלו לתקשר עם השרת שלך.
* **טוקן ניהול:** ניתן להפיק את הטוקן מתוך לשונית האבטחה באתר הניהול של ימות המשיח.

---

## מה התוסף עושה?
התוסף מקים ומנהל 3 שירותים מרכזיים לשימוש באוטומציות ובבית החכם:

1. **ימות: הגדרת שלוחה**
   * **קוד שירות:** `ha-yemot.create_extension`
   * **תיאור:** יצירה והגדרה אוטומטית של שלוחה טלפונית המקושרת ישירות לישות ב-Home Assistant (להקראת סטטוסים והפעלת פעולות).

2. **ימות: שליחת צנתוק (התראה)**
   * **קוד שירות:** `ha-yemot.send_tzintuk`
   * **תיאור:** שליחת צנתוק למספרי טלפון (כולל תמיכה במספר מציג אופציונלי).

3. **ימות: הוצאת שיחה קולית**
   * **קוד שירות:** `ha-yemot.send_tts`
   * **תיאור:** שליחת הודעות קוליות / טקסט לדיבור (TTS) למספרי טלפון.

---

## הוראות התקנה

ניתן להתקין את התוסף בשתי דרכים: דרך חנות התוספים HACS (מומלץ) או בהתקנה ידנית.

### אפשרות 1: התקנה דרך HACS (מומלץ)
זוהי הדרך הקלה והמומלצת ביותר, שתאפשר לך גם לקבל עדכונים עתידיים בלחיצת כפתור:
1. פתח את Home Assistant והיכנס ל-**HACS**.
2. לחץ על תפריט שלוש הנקודות בפינה העליונה ובחר ב-**Custom repositories**.
3. בשדה הקישור (Repository), הדבק את הכתובת של מאגר זה. `https://github.com/meni123/ha-yemot`

4. בשדה הקטגוריה (Category), בחר ב-**Integration**.
5. לחץ על **Add** (הוסף).
6. כעת חפש את `Yemot API` ברשימת התוספים ב-HACS ולחץ על התקן.
7. הפעל מחדש (Restart) את Home Assistant.

### אפשרות 2: התקנה ידנית
אם אין ברשותך HACS, תוכל להתקין את הקבצים באופן ידני:
1. הורד את תיקיית המאגר.
2. העתק את התיקייה `ha_yemot` (שנמצאת בתוך `custom_components`) אל תוך תיקיית `custom_components` בשרת ה-Home Assistant שלך.
   * הנתיב הסופי אמור להיות: `/config/custom_components/ha_yemot/`
3. הפעל מחדש (Restart) את Home Assistant.

---

## הגדרה והפעלה (לאחר ההתקנה)
לאחר שהתקנת את התוסף (באחת משתי הדרכים) והפעלת את השרת מחדש:
1. היכנס אל **הגדרות** -> **התקנים ושירותים** (Devices & Services).
2. לחץ על **הוסף שילוב** (Add Integration) בפינה התחתונה.
3. חפש את `Yemot HaMashiach API` ובחר בו.
4. מלא בטופס את הכתובת החיצונית של השרת שלך ואת טוקן הניהול של ימות.
